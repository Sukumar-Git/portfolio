- **Contact**: email, GitHub and LinkedIn.

## Built with

- Plain **HTML, CSS and JavaScript** in a single `index.html` file, with no build step and no framework.
- Fonts from Google Fonts: Cinzel, Cormorant Garamond, DM Sans and JetBrains Mono.
- Inline SVG illustrations for the project cards.
- Hosted on **Vercel**.

## Run it locally

No install is needed. Download or clone the repo and open `index.html` in your browser.

```bash
git clone https://github.com/Sukumar-Git/portfolio.git
cd portfolio
# then open index.html in your browser
```

## Deploy

1. Push the repo to GitHub, with `index.html` at the top level.
2. Import it into [Vercel](https://vercel.com/new).
3. Set **Framework Preset** to **Other** and leave the build command and output directory empty.
4. Deploy.
